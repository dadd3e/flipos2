# **App Name**: Reseller Insights

## Core Features:

- Inventory Tracking: Enable manual entry of all items, quantities, purchase prices and conditions.
- Sales Logging: Enable sales entry and logging of revenue and shipping costs.
- AI-Powered Valuation Report: Generate an inventory valuation report. This feature leverages a tool to decide whether or not to use current prices on reseller sites such as Ebay.
- Profit and Loss Report: Enable report generation for total revenue, net profit and ROI, to evaluate overall financial performance.
- Alerts: Allow users to set custom alerts, e.g., low stock notifications, high-value sales opportunities and listing expiration dates.

## Style Guidelines:

- Primary color: Deep blue (#3F51B5) to convey professionalism and trust.
- Background color: Light gray (#F0F2F5), providing a clean and neutral backdrop.
- Accent color: Teal (#009688), to highlight key metrics and calls to action.
- Body and headline font: 'Inter' sans-serif for a modern, objective, neutral look; suitable for both headlines and body text.
- Simple and clear icons that relate to inventory, sales and finance to aid quick recognition.
- Clean layout with cards and tables to present the data effectively.
